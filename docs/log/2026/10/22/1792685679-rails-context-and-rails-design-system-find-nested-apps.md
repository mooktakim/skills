- rails-context 0.16.0, rails-design-system 0.20.0: the hooks' `app-roots.sh` (`app_roots`, `design_roots`) now find an app up to three levels below the project directory (`apps/server/`, `packages/x/y/`), not only one. The search stops at an app it found and follows a symlink only to a first-level app (as the old one-level glob did), and skips hidden directories and `node_modules`, `vendor`, `tmp`, `log`, `storage`, `coverage`, `dist`, `build`, `target`, so it stays cheap on every tool call. Found while setting up both plugins in the oasis-kids monorepo (app at `apps/server/`), where the edit-time hooks never ran from the repo root.
- `rails-context/scripts/inject_context` had its own one-level `Dir.glob` copy of the search; it now takes the apps from `inject-context.sh` in `APP_ROOTS`, so there is one search per plugin.
- `audit_design` also scans `app/assets/tailwind/` (tailwindcss-rails 4 keeps the entry CSS and component classes there). Its token checks now skip lines inside CSS `@theme` blocks: the entry CSS holds the token values there by design, and every token would otherwise be a raw-hex finding. Project rules still apply inside `@theme`.
- design-reviewer's diff scope lists `app/assets/tailwind/` too.
