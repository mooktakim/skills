# rails-view-component 0.1.0: ViewComponent standard and library audit

- Origin: user asked for research on ViewComponent best practices, Turbo/Hotwire integration, and forms, modelled on rails-minitest. Decisions: plugin name `rails-view-component`; replace the user's own `viewcomponent` and `turbo-view-component` skills (config_files/claude/skills) and carry over the TurboViewComponent pattern; forms use the app's own builder or Rails' default (no custom FormBuilder, no forms gem); no design standards (structure, code, tests, composability only; styling defers to rails-design-system); agent wanted eventually but deferred.
- Sources: 4 research agents (VC 4.15 docs/changelog/source, turbo-rails/stimulus-rails/importmap source, Primer, GOV.UK govuk-components + govuk-formbuilder, Evil Martians, 37signals morphing). Then a fact-check agent: 14 problems fixed (controller `render Component` DOES use the layout; before_render runs BEFORE render?; sidecar stimulus ids repeat the name; Propshaft path exposes component sources; 4.15 ExperimentallyCacheable fixes outer cache digests; use_global_output_buffer was gone in 2.62; etc.). Confirmed: broadcast_replace_later_to + renderable: Klass.render_later + layout: false works; Serializable in a base class works for subclasses.
- Key v4 facts: use_helpers removed; VC 4.13 Serializable/render_later; 4.14 ReusedInstanceError (CVE-2026-54497); 4.10 fixed form-helper capture order; components ignore a controller's default_form_builder; turbo_frame_tag needs `include Turbo::FramesHelper`.
- TurboViewComponent revised: class method `broadcast_update(**args)` runs the `changes_to` filter sync (saved_changes) and enqueues `render_later`; root is `tag.div id: target_id` (not a frame - frames capture links); no render? on broadcasters (target vanishes); `target_record` replaces `frame_id` overrides; migration steps for the old frame/sync version; tests via fixtures + perform_enqueued_jobs + capture_turbo_stream_broadcasts (no send(:should_broadcast?)).
- Plugin: SKILL.md (detect, 17 rules, 6 hard; writing vs approval-gated library mode) + 10 references; `scripts/audit_components` (Ruby 2.6+, 17 rules, previews/tests coverage); SessionStart hook in Rails apps with view_component. Tested: test/audit_components_test.rb (8) + 2 hook tests, green on Ruby 4 and /usr/bin/ruby 2.6. Audit run on blogger (the TurboViewComponent app: 6 frame-wrapper, 18 unprocessable-entity, real query/html-safe hits), dfe apply-for-teacher-training (v2, 198 components), acquintel.
- Open: delete the old skills + update config_files rails.md:7 (asked user); an agent for components (user wants one, decide later; rails-hotwire overlap and zero-delegation data, count due ~2026-10-22).
