- toolsmith 0.4.0: new command `toolsmith-conflict-resolve`. It resolves git merge-conflict blocks in files as one all-or-nothing change: `--show` prints the blocks under numbered `@@ <path> <block>` headers, and a stdin spec gives each block `ours`, `theirs`, `both` or `text` (`*` for the rest of a file). It replaces the Python/Ruby regex scripts of the `conflict-resolve` family (106 calls in 55 sessions, 36 projects in the 2026-10-16 scan). User approved the design.
- `--show` with no paths lists every conflicted file from `git diff --diff-filter=U`, named relative to the current directory; a first version used `--relative` and missed root files from a subdirectory, found by trying it on a real rebase.
- Fixed the clippy warnings in the other crates (`map_or(false, ..)` to `is_some_and`, `repeat().take()` to `repeat_n`, a single-arm `match` in common/guide.rs).
