# 2026-10-24 toolsmith: ci-wait and literal-replace patterns count only their own job
- Goal: usage review 2026-10-24 found two families too broad, so their share numbers (and reminders) were wrong.
- Changed (toolsmith 0.4.2, families.json): ci-wait now matches only waiting (`gh run watch`, `gh pr checks --watch`, a sleep/until/while loop around `gh pr checks`/`gh run list|view`) and reading failures (`gh run view --log-failed`); one-off `gh run view --json ...` status checks no longer count. literal-replace now matches only literal replacements: `sed -i`/`perl -pi` whose `s` pattern has no regex characters, Python `.replace(` (not `re.sub`), Ruby `sub`/`gsub` with a string. Checked on 20 real and made-up commands before the change. Titles follow the new scope. Rescanned: ci-wait W43 share 13% -> 50%; text-replace W43 still 18% (2,507 literal replacements), so that drop is real.
- Open questions: after the once-per-session reminder, only 12% of later literal replacements used text-replace (3,156 old vs 425, 68 of 360 reminded sessions) and 17% for file-lines (823 vs 169); reminder strength is the user's call (block mode needs approval).
