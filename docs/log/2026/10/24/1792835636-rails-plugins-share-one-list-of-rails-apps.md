# 2026-10-24 Rails plugins share one list of Rails apps
- Goal (user request): search the project for Rails apps once, keep the list, and have every Rails plugin hook use it, so hooks run only in projects with Rails apps and only for those apps.
- Changed: new hooks/rails-apps.sh, byte-identical in all 7 Rails plugins (test checks). `rails_apps` lists every directory whose config/application.rb defines Rails::Application, at any depth git sees (`git ls-files --cached --others --exclude-standard`, so .gitignore applies; `find` with the old prune list outside git), plus a symlinked app one level down; it skips hidden paths, node_modules/vendor/tmp, engine test/dummy and spec/dummy apps, and apps inside another app. The list lives in $TMPDIR/claude-rails-apps/<cksum of project dir>, shared by all plugins: SessionStart hooks pass `fresh`, every other hook reads it. A tool call that names `rails new` or config/application.rb drops it (`rails_apps_forget`, called before a hook's early exit), so the first hook after that call searches again; cached apps that are gone are left out. `rails_app_of` maps a call to its app (file_path, else cwd, else a path the command names as a whole word). Replaces rails-context and rails-design-system's app-roots.sh (three levels) and the inline one-level loops in rails-generators, rails-hotwire, rails-minitest, rails-view-component and rails-specialists. First-touch hooks now act only for a path inside an app; guard.sh is silent without a Rails app. Versions: rails-context 0.17.0, rails-design-system 0.21.0, rails-generators 0.3.0, rails-hotwire 0.4.0, rails-minitest 0.3.0, rails-view-component 0.4.0, rails-specialists 0.6.0.
- Failed / dead ends: a first version let a loop's exit status mark an app as nested; a `case` match missed `cd web` (no slash). Both fixed and tested. guard.sh and the first-touch hooks exited before the list could be dropped on a Write of config/application.rb, so with only rails-generators installed a new app stayed unseen until the next session; found by the guard test.
- Verified: bin/test and TEST_RUBY=/usr/bin/ruby TEST_BASH=/bin/bash bin/test pass (187 runs). On oasis-kids (app at apps/server, 2,446 files) a fresh search takes 83 ms and a cached read 7 ms; all five SessionStart notes now fire there (before: silent), and first-touch fires inside apps/server and not outside it.
