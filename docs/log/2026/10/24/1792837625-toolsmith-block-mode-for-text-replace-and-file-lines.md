# 2026-10-24 toolsmith: block mode for text-replace and file-lines
- Goal (user approved option 1 of the usage review, 2026-10-24): the once-per-session reminder was followed in only 12% of later literal replacements (3,156 old vs 425 text-replace, 68 of 360 reminded sessions) and 17% of later multi-range sed reads (823 vs 169 file-lines); the misses were exact jobs for the tools (python3 heredocs with `assert old in s` + `.replace(`, several files).
- Changed (toolsmith 0.5.0): `toolsmith-text-replace` and `toolsmith-file-lines` are `"mode": "block"`, so the PreToolUse hook denies their (now narrow) patterns; the refusal also names Claude Code's own Edit or Read tool as an alternative. Other tools still only remind. README says which tools block and why. Reminder tests run every tool in remind mode; a new test checks the real modes end to end.
- Verified: bin/test and TEST_RUBY=/usr/bin/ruby TEST_BASH=/bin/bash bin/test pass (189 runs). A headless sonnet session with --plugin-dir toolsmith asked to use `sed -i`: the hook denied it, Claude ran `toolsmith-text-replace --llm`, then made the change with the tool.
