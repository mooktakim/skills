- `hooks/log-context.sh` (bash, field extraction by grep/sed, no Ruby startup): modes start (SessionStart startup|clear: HEAD), load (InstructionsLoaded), read (PostToolUse Read of CLAUDE.md/AGENTS.md - direct reads are not load events), stop (Stop: `git diff --name-only <session start HEAD>` + untracked, so Bash edits count; skipped when unchanged since last turn). Writes `<git common dir>/claude-context-log.jsonl` (shared by worktrees, never committed); only in projects with bin/audit_context; bounded at ~5 MB -> last 10k events.
- `scripts/context_report` (Ruby stdlib 2.6+, run from the plugin, not copied into apps): per directory CLAUDE.md -> Worked (sessions changing code it owns = nearest ancestor context file), Reached (load reasons + read), Gap, size; root size/load count; never-reached list. `--days N` (default 30).
- SKILL.md maintenance gains a 5th kind, "Reach review" (gap -> make the file reach; never reached -> merge candidate). README section.
- Tests: 3 new (silent without rails-context; full session flow incl. AGENTS.md read mapping, non-context reads ignored, duplicate turn not logged, report numbers, --days 0). Repo test caught a missing chmod +x on the new script. Suite 73 tests green on Ruby 4.0 and Ruby 2.6 + bash 3.2.
