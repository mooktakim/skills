# Repo CI: GitHub Actions runs the test suite

- `.github/workflows/test.yml` (push to main + PRs): Linux on Ruby 3.3 and 4.0 (setup-ruby), Linux on Ruby 2.6 (`container: ruby:2.6`, Debian, git 2.30), macOS with Ruby 4.0 then `TEST_RUBY=/usr/bin/ruby TEST_BASH=/bin/bash` (system Ruby 2.6 for the scripts, bash 3.2 for the hooks; falls back if the runner has no /usr/bin/ruby). Action versions match the user's Rails apps (checkout@v7, setup-ruby@v1).
- Harness: `git init` + `symbolic-ref HEAD refs/heads/main` instead of `init -b` (git < 2.28 in old containers); `TEST_BASH` selects the bash for hook tests.
- New `test/repo_test.rb` (6 tests): marketplace lists every plugin with matching names + semver, root README row per plugin, SKILL/agent frontmatter names match files, hooks.json parses and every ${CLAUDE_PLUGIN_ROOT} path exists, shipped scripts are executable `#!/usr/bin/env ruby` that compiles, hook .sh parse as bash. Suite now 68 tests / 261 assertions.
- Verified locally: Ruby 4.0, TEST_RUBY=/usr/bin/ruby + TEST_BASH=/bin/bash, and the ruby:2.6 container in Docker. Not yet run on GitHub (needs a push). `claude plugin validate` is not in CI (needs the claude CLI).
