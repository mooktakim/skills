# rails-design-system 0.10.0: design-reviewer agent

- Report improvement 14 (user approved: code-only default, screenshots on request, auto before commit/PR, sweep mode in maintenance). Gap it fills: bin/audit_design is token-only; maynard had 0 audit findings but 23 inconsistencies in its 10-01 UI review ("no dot" rule given 3x, status shown 3 ways, AED vs symbol).
- First agent in this plugin: `agents/design-reviewer.md` (read-only via disallowedTools). Loads README router, conventions.md, section design/tokens/shell frames, then the specs the files use. Checks in order: conventions, frames/patterns, components (hand-rolled markup, unlisted axes, missing states, raw class strings), design.md rules, stale specs (incl. "Realized as" drift). Every finding must cite a spec line; uncited = taste, listed as a question only. Token checks deferred to bin/audit_design (run once, one line). Diff mode default; sweep mode groups repeats. Screenshots via agent-browser only when caller asks and gives a dev server URL; never starts servers or submits data.
- SessionStart hook `hooks/reviewer-context.sh` (startup|clear|compact, only when docs/design-system/README.md exists) tells the main session to delegate before commit/PR. Maintenance "Conventions and frames" work now dispatches one sweep agent per section, counted in the plan's fan-out.
- Trial run (general-purpose agent following the file, read-only) on maynard's 6 bid-panel commits: 114k tokens, ~1.5 min; 0 false defects, 4 real stale specs (dialog trigger axis/slot, bid-panel primary rule + posting note, form-field prefix, contact-card note), 2 good "not in the specs" questions. Its notes led to 4 fixes: shell pattern may not be named app-shell.md; verify caller-named commits are in the range (merged branches dropped one); "Realized as" drift counts as stale; large spec files may be read in part.
- READMEs, plugin.json and marketplace description updated.
