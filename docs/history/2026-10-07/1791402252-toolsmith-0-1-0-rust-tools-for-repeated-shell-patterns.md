# toolsmith 0.1.0: Rust tools for repeated shell patterns

- Origin: user asked for an analysis of all Claude Code transcripts (45,820 tool calls, 294 sessions, 20 projects, 2026-08-21 to 10-07) to find repeated edit patterns worth a Rust tool. Report artifact: https://claude.ai/artifact/2Wcy5KJVZ9Wbd9Gkor5WBs. Main finding: 4,926 Bash calls were inline Python/Ruby/sed/perl find-and-replace scripts (vs 2,745 Edit tool calls, only 20 failed); next: history-log entries by hand (~870), commit chains (1,026), CI polling (588 `gh pr checks`).
- User requirements: a plugin (not just a skill) to keep adding tools; each tool has one specific intent, an appropriate name, an LLM guide flag, full tests; continuous history scans; usage tracking to show whether tools help; never interfere with existing commands; prefix `toolsmith-`.
- Design: `crates/<object>-<verb>/` Rust, std only; `tool.json` manifest is the single source for `--help`, `--llm` and the tested examples (test runs each example against the binary and compares every file before/after). `bin/<name>` 2-line shim -> `libexec/shim` builds on demand (cargo) when binary missing/stale. Plugin `bin/` is on the Bash tool PATH (verified in docs: code.claude.com/docs/en/plugins/components), after user PATH, so tools cannot shadow commands; SessionStart hook drops a tool another command shadows.
- `families.json`: pattern families shared by `scripts/analyse` (scan/examples/adoption) and the PreToolUse Bash hook (`scripts/registry check`: additionalContext reminder; `mode: block` -> deny, opt-in per tool). Hook ~60 ms on /usr/bin/ruby.
- Tracking: Rust `Tool::exit` appends to `~/.local/state/toolsmith/usage.jsonl` (no args/input); hook logs nudges. `metrics/weekly.json` = weekly counts, max-merged per scan, because cleanupPeriodDays is unset (30 days) - transcripts older than that vanish. Baseline committed. Asked user whether to raise cleanupPeriodDays; no answer yet.
- First tools: `toolsmith-text-replace` (spec `@@ path [--all|--count N]`, `-`/`+` lines, literal, all-or-nothing, atomic rename, near-miss hints) and `toolsmith-history-add`. Used text-replace for most later edits in this session.
- Tests: test/toolsmith_test.rb (18) + 20 Rust unit tests; contract test proven to fail on a wrong example. CI: REQUIRE_CARGO on Linux/macOS jobs; Ruby 2.6 container skips tool tests (no cargo). Suite 96 green on Ruby 4.0 and 2.6 + bash 3.2. CI not yet run (push needs approval).
