- Origin: user asked for deep Hotwire research "in a similar way" to rails-view-component, "create the best skill". Skill only (no agent asked); ViewComponent wiring stays in rails-view-component; no design rules.
- Research: 6 agents - Turbo Drive/Frames, Streams/broadcasts/morphing, Stimulus, 37signals code (Fizzy 567a296, once-campfire, writebook: 69/35/22 controllers, .turbo_stream.erb templates, broadcasts_refreshes in model concerns, native dialog + one dialog controller, morph guards, authorised RoomMessagesChannel), UX patterns/testing/Native, repo overlap. Real hits kept: fizzy render :new without status, blogger data: { confirm: } under Turbo.
